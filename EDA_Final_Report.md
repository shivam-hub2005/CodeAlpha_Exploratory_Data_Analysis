# CodeAlpha Internship – Exploratory Data Analysis (EDA)

## 1. Project Overview
This project performs Exploratory Data Analysis on the UCI Online Retail dataset to understand sales performance, customer purchasing behavior, product performance, and country-wise revenue distribution.

## 2. Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 3. Dataset Overview
- Original Records: 541,909
- Columns: 8
- Dataset: Online Retail
- Data Cleaning: Duplicate records removed.

## 4. Data Cleaning
- Removed duplicate records.
- Investigated missing values.
- Identified negative quantities and prices.
- Identified cancellation transactions.
- Created a separate sales dataset for revenue analysis.
- Calculated TotalPrice using Quantity × UnitPrice.

## 5. Exploratory Data Analysis
The following analyses were performed:
- Monthly Revenue Analysis
- Country-wise Sales Analysis
- Product-wise Sales Analysis
- Customer Analysis
- KPI Analysis
- Data Visualization

## 6. Key Business Findings
- Total Revenue: £10,642,110.80
- Best Sales Month: November 2011
- Best Month Revenue: £1,503,866.78
- Top Revenue Country: United Kingdom
- UK Revenue: £9,001,744.09
- Top Product by Revenue: DOTCOM POSTAGE
Note: DOTCOM POSTAGE represents a postage-related charge, not an ordinary merchandise product. It should be interpreted separately from physical products.
- Top Customer ID: 14646
- Top Customer Spending: £280,206.02
- Average Order Value: £533.17

## 7. Conclusion
The analysis highlights the United Kingdom as the leading revenue-generating market and November 2011 as the strongest sales month in the dataset. Customer and product-level analysis provides additional insights into purchasing behavior and business performance.

This project demonstrates practical skills in data cleaning, exploratory data analysis, Python programming, and data visualization.
