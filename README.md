# CodeAlpha Internship Project – Exploratory Data Analysis

## Online Retail Sales Analysis

### Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the UCI Online Retail dataset using Python. The objective is to identify sales trends, product performance, customer behavior, and country-wise revenue patterns.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Project Tasks
1. Data Loading and Inspection
2. Data Cleaning
3. Duplicate and Missing Value Analysis
4. Sales Transaction Filtering
5. Monthly Revenue Analysis
6. Country-wise Sales Analysis
7. Product-wise Sales Analysis
8. Customer Analysis
9. Business Insights
10. Data Visualization

### Key Findings
- Total Revenue: £10,642,110.80
- Best Sales Month: November 2011
- Top Revenue Country: United Kingdom
- Top Product by Revenue: DOTCOM POSTAGE
- Top Customer ID: 14646

### Project Structure
- `dataset/` – Dataset files (if included)
- `notebooks/` – Jupyter Notebook analysis
- `screenshots/` – Project visualizations
- `EDA_Final_Report.md` – Final analysis report
- `business_insights.txt` – Business findings
- `requirements.txt` – Python dependencies

### Dataset Source
UCI Online Retail Dataset: https://archive.ics.uci.edu/datasets?search=Online+Retail

### How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open `notebooks/EDA_Analysis.ipynb` in Jupyter Notebook.
4. Place the dataset in the `dataset/` folder.
5. Run the notebook cells.
